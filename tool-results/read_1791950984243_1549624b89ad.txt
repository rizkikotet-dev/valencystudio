     5→Goal: Fullstack launch / promotion site for **ValencyStudio - Spoofer**

    21→### API contract (agreed — backend Task 2-a must implement exactly this)
    22→
    23→1. `GET /api/stats` →
    24→   `{ github: { stars:number, forks:number, watchers:number, openIssues:number },
    25→      release: { tag:string, name:string, publishedAt:string|null, url:string,
    26→        assets: { platform:"windows"|"macos"|"linux", name:string, url:string, downloads:number }[] },
    27→      totals: { downloads:number|null },
    28→      site: { downloadClicks:number, subscribers:number },
    29→      source: "github"|"fallback" }`
    30→   In-memory cache TTL 10 min; on GitHub failure use fallback constants (v3.0.2).
    31→2. `GET /api/changelog` → `{ releases: { tag, name, publishedAt, url, notes:string }[],
    32→      source:"github"|"fallback" }` — latest 8 releases, notes plain text (strip markdown).
    33→3. `POST /api/subscribe` body `{ email }` (zod-validated) → `{ ok:true, subscribers:number }`
    34→   or `{ ok:false, error:string }` (400/500). Unique email via Prisma, upsert on conflict.
    35→4. `POST /api/downloads` body `{ platform:"windows"|"macos"|"linux" }` →
    36→   `{ ok:true, clicks:{ windows:number, macos:number, linux:number, total:number } }`
    37→
    38→DB models (replace scaffold User/Post):
    39→- `Subscriber { id String @id @default(cuid()), email String @unique, createdAt DateTime @default(now()) }`
    40→- `DownloadEvent { id String @id @default(cuid()), platform String, createdAt DateTime @default(now()) }`
    41→
    42→Repo facts for copy/fallback: stars≈1, GPL-3.0, Discord https://discord.gg/6RHuXU9DCv,
    43→issues templates bug_report.md / feature_request.md, releases page
    44→https://github.com/valency-studio/valencystudio-spoofer/releases/latest.
